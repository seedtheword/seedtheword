    📊 Team Portal — the basics

    The Team Portal is where the team works day-to-day. Which tabs each person sees depends on their permissions (set in Content Studio → Members). Tap a card's ? for a walkthrough.

    📷

    Scan / Log inventory

    Scan a QR or add an item by hand; logs to today's outreach.

    💰

    Finance

    Log expenses, deposits/donations, and receipts. One form for money in and out.

    🛒

    Store Orders

    Received → Confirming → Packing → Shipped → Delivered. Packing logs items out.

    📣

    Announcements

    Post to admins, members, public (community + Telegram), or email.

    💬

    Direct messages

    Private Instagram-style DMs between team members, with block/report.

    🔔

    Incoming Activity

    Prayers, orders, Bible requests & contacts funnel here to review & respond.

    Good to know

    🙏 Prayer & thanksgiving flow

    When someone submits a prayer and ticks "share publicly," it becomes a real post on the community page — so the team can reply in the open. Replies you send from Incoming Activity post as a public comment on that prayer. Private requests stay private and show "not shared publicly."

    ✨ Content Studio (super-admin)

    A super-admin dashboard at admin/dashboard.html — open it from the Team Portal → Content tab. Publish live to the site and manage operations, no code.

    ✨

    🗣️

    🗺️

    Outreach Map

    Add countries/states/cities. Published countries drive the globe + "countries reached."

    👥

    Members & permissions

    Set each person's role and fine-tune exactly which tabs they can open.

    🎟️

    Comp codes

    Generate a code that lets someone place a store order at no charge.

    🛡️

    Moderation

    Review DM reports and restrict who can message whom.

    The permission list

    What each permission unlocks

    • Inventory scanner — scan/log Bibles in the field.
    • Finance — log expenses, deposits & view finances.
    • Store orders — process & fulfil store orders.
    • Announcements — post announcements (also sees Incoming Activity).
    • Training admin — log training for members.
    • Content Studio — publish stories / testimonies / map.

    • Moderation — DM restrictions & reports (also sees Incoming Activity).

    ✏️ The Editor — change site content

    The Editor is a no-code form for the site's content files (recommendations, verses, images, Telegram config, bundles, the homepage carousel, and more). It reads and writes them for you and commits straight to the site. Launch it from ✏️ Open the Editor at the bottom of the sidebar.

    ✏️

    How the Editor works

    Connect once → pick what to edit → fill the form → review the diff → commit.

    First-time only

    🔐 Connect your GitHub token

    The very first time, the Editor walks you through creating a GitHub access token (Contents: Read & Write) and pasting it in. It's stored only in your browser and re-checked each visit — after that you go straight to picking what to edit.

    🚀 Deploy — push backend changes live

    The website auto-deploys on every commit, but the backend (Google Apps Script) must be redeployed by hand after its code changes.

    🚀

    Redeploy routine

    Paste the .gs files → Deploy → Manage deployments → edit → New version → Deploy.

    Rule of thumb: if a new portal feature "does nothing" or shows old data, the backend probably wasn't redeployed. Re-run the routine and hard-refresh (Ctrl+Shift+R). The full paste/setup checklist lives in docs/apps-script/DEPLOY-CHECKLIST.md.

    🧯 Troubleshoot

    Quick fixes by symptom.

    A change isn't showing up

    Hard-refresh: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac). GitHub Pages takes ~30–60s to rebuild after a commit; calendar events take ~1 minute.

    A portal feature does nothing / shows old data

    The backend probably needs a redeploy (New version) — see Deploy above. Also confirm you have the permission for that tab.

    Telegram announcements aren't sending

    Use the Test Telegram button in the announcement composer — it reports the exact cause (token not set, bot not a channel admin, wrong thread).

    The Editor won't save

    Your GitHub token may have expired — the Editor will ask you to reconnect. Your in-progress edits are kept as a draft.
