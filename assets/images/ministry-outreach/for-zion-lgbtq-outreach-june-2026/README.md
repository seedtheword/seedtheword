# For Zion Ministries — LGBTQ+ Evangelism Outreach, June 2026
# Lake Stevens, WA

Drop photos and videos from this outreach into this folder, then update
`images.json` with the file list.

## images.json format
```json
{
  "media": [
    { "file": "01.jpg", "type": "photo", "caption": "" },
    { "file": "02.jpg", "type": "photo", "caption": "" },
    { "file": "video-01.mp4", "type": "video", "caption": "From the field" }
  ]
}
```

Photos will appear in:
- The outreach card slideshow on news.html
- The 3-thumbnail preview strip on the For Zion Ministries partner card on community.html
